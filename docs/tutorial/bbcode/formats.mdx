The following table summarizes the main input and output formats of the default renderer.

| <center>Markdown Format</center> | <center>BBCode Format</center> |
| :-------------- | :------------ |
| `## title` | `[h2]title[/h2]` |
| `text` | `text` |
| `**bold text**` | `[b]bold text[/b]` |
| `*italic text*` | `[i]italic text[/i]` |
| `<u>underlined text</u>` | `[u]underlined text[/u]` |
| `<ins>underlined text</ins>` | `[u]underlined text[/u]` |
| `~~strike text~~` | `[strike]strike text[/strike]` |
| `==spoiler text==` | `[spoiler]spoiler text[/spoiler]` |
| `-----` | `[hr][/hr]` |
| `[Link](https://google.com)` | `[url=https://google.com]Link[/url]` |
| `![image](image.png)` | *(Removed)* |
| `> quote block` | `[quote]quote block[/quote]` |
| <pre><code>quote block<br/>{"<cite>with author</cite>"}</code></pre> | `[quote=with author]quote block[/quote]` |
| <pre><code>{"```"}<br/>Multi-line codes<br/>{"```"}</code></pre> | <pre><code>{"[code]"}<br/>Multi-line codes<br/>{"[/code]"}</code></pre> |
| <code>{"`inline code`"}</code> | `[noparse]inline code[/noparse]` |
| `* Unordered list` | `[list][*] Unordered list[/list]` |
| `1. Ordered list` | `[olist][*] Ordered list[/olist]` |
| `\| table \| ...` | `[table][tr][th]table[/th]...[/tr][/table]` |
| <pre><code>{"> [!caution]"}<br/>{"Multi-line spoiler text."}</code></pre> | <pre><code>{"[spoiler]"}<br/>Multi-line spoiler text.<br/>{"[/spoiler]"}</code></pre> |
| <pre><code>{"> [!important]"}<br/>{"Multi-line bold text."}</code></pre> | <pre><code>{"[b]"}<br/>Multi-line bold text.<br/>{"[/b]"}</code></pre> |
| <pre><code>{"> [!warning]"}<br/>{"Multi-line underlined text."}</code></pre> | <pre><code>{"[u]"}<br/>Multi-line underlined text.<br/>{"[/u]"}</code></pre> |
