This section introduces the built-in renderer variants that render BBCode in different formats. They are designed for different scenarios.

## 1. Prefer tables rather than lists

Steam's list style does not look neat in many cases. For example, the spacing between list items is either too small or too large. The list indents may be unwanted. As a result, users may intend to avoid using lists. The [BBCodeRendererTablePreferred](../../apis/bbcode/renderer/variants/BBCodeRendererTablePreferred.mdx) implements special rendering rules in which all Markdown/HTML lists are replaced by tables in the rendered files:

```python
# diff-remove-next-line
stet.BBCodeRenderer().render(doc)
# diff-add-next-line
stet.bbcode.renderer.BBCodeRendererTablePreferred().render(doc)
```

:::info

This style was used to render reviews before 2026 because lists weren't rendered correctly. After Q1 2026, Steam made a significant change to the reviews displayed on the store page, which causes tables to fail to render but lists to render correctly. Therefore, this renderer is not very useful now.

:::

## 2. Prefer lists rather than tables

Since Steam does not render tables correctly on store pages, users may prefer lists instead. We offer a special renderer, [BBCodeRendererListPreferred](../../apis/bbcode/renderer/variants/BBCodeRendererListPreferred.mdx), for this scenario.

```python
# diff-remove-next-line
stet.BBCodeRenderer().render(doc)
# diff-add-next-line
stet.bbcode.renderer.BBCodeRendererListPreferred().render(doc)
```

## 3. Renderer for writing reviews

:::info

After the Steam major update in Q1, 2026, many previously working styles have become problematic on the store page. For example, the `[table]` was considered a very good choice to align review items. However, it is not rendered at all now.

Briefly, I can confirm that the ordered and unordered lists can be rendered on both the store and review pages. However, on the review (detail) page, there is a vertical margin for each list, but that margin is absent on the store page, which makes this feature still half-baked.

After several experiments, I can confirm that the following features are totally broken during the current store-page review rendering:

* `[table]`

The following features have style issues:

* `[h2][h3]`: On the store page, h2 will become white small text, while h3 is still larger blue text, which make h2 smaller than h3.

Currently, this package provides a workaround for such issues by implementing a variant of the renderer with format-transformation features. The following example first reads a BBCode file, then transforms all tables into lists before rendering the content to a new file.

:::

[BBCodeRendererListPreferred](../../apis/bbcode/renderer/variants/BBCodeRendererListPreferred.mdx) only implements minimal conversion from tables to lists. Beyond that, I optimized the rendering rules to match my preferences for writing reviews. This deeply customized renderer, [BBCodeRendererForReview](../../apis/bbcode/renderer/variants/BBCodeRendererForReview.mdx), will specialize in itemized review points:

```python
# diff-remove-next-line
stet.BBCodeRenderer().render(doc)
# diff-add-next-line
stet.bbcode.renderer.BBCodeRendererForReview().render(doc)
```
