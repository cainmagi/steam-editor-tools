When writing guides, users may need to access a game's achievement descriptions and icons. Currently, Steam does not expose a public API. As a result, many existing solutions call [the developer's features<IconExternalLink/>][link-steamach], which requires a Steam API key.

Our package provides an alternative solution that does not require login credentials. The basic ideas can be explained as follows:

1. The achievement list can be accessed on the store page. However, this page does not show descriptions for hidden achievements.
2. When accessing a user's public profile, the icons for those locked achievements can be found.
3. If a user has unlocked an achievement, its description will be available even if the achievement is hidden.

## 1. Get achievement list

The simplest way to get the list is to use the method [`get_achievement_list`](../../apis/steaminfo/query/get_achievement_list.mdx). The following example accesses the achievements of the game `"The Hex"`.

```python
names = stet.query_app_by_name_simple("The Hex")
achievements = stet.get_achievement_list(names[0])
```

  <JSONGrid data="game-achievements"/>

The above information, [`AchievementList`](../../apis/steaminfo/data/achievements/AchievementList.mdx), is the same as what can be accessed on [the game page<IconExternalLink/>][link-hex].

### 1.1. Get more details

The achievement list can be further completed by adding details from user profiles. In the following example, we access two users' profiles. `nonno24` has unlocked all achievements, while `cainmagi` has not unlocked any achievements:

```python
achievements = stet.get_achievement_list(
    names[0], extra_user_profiles=["nonno24", "cainmagi"]
)
```

<Admonition type="note" icon={<InlineIcon icon={mdiCodeJSON} vspace={-0.35}/>} title={<code>achievements</code>}>
  <JSONGrid data="game-achievements-full"/>
</Admonition>

:::warning

So far, our package does not have a way to access the icons for those locked, hidden achievements. Even in the full list above, the icons for those locked versions remain `null`.

:::

### 1.2. Get the list in other langauges

Users can specify the language when acquiring the achievement list:

```python
achievements = stet.get_achievement_list(
    names[0], lang="schinese", extra_user_profiles=["nonno24", "cainmagi"]
)
```

which yields

## 2. Render the achievement list as BBCode

The achievement list can be rendered as a BBCode file. Users can further integrate the snippets in the rendered file into their guides.

```python
with open("achievements.bbcode", "w", encoding="utf-8") as fobj:
    fobj.write(
        stet.BBCodeRenderer().render(
            stet.DocumentParser().parse_achievements(achievements)
        )
    )
```

The following command will save all icons in a folder:

```python
achievements.save_icons("out-icon-dir")
```
