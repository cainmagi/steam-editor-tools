## 1. Example scripts

If the project is cloned, use can find the examples in the `./examples` folder. Use the following command to run an example script:

```sh
pythom -m examples.markdown_to_bbcode
```

where `markdown_to_bbcode` is the example script name. It can be replaced by other scripts offered in the following list:

| <center>Example</center>                        | <center>Description</center>                                                            |
| :---------------------------------------------- | :-------------------------------------------------------------------------------------- |
| <DemoLink script="markdown_to_bbcode"/>         | A minimal example converting Markdown to BBCode.                                        |
| <DemoLink script="bbcode_table_to_list"/>       | An example of loading a BBCode file, and convert the tables inside it to lists.         |
| <DemoLink script="bbcode_achievements"/>        | Download achievement information of a game and save it as a BBCode list.                |
| <DemoLink script="save_description_of_a_game"/> | Save the "about the game" section of a Steam app as an HTML file.                       |
| <DemoLink script="download_screenshots"/>       | Download all official screenshots of a game and create thumbnails of them.              |
| <DemoLink script="download_a_guide"/>           | Fetch a Steam guide and save it as a BBCode file.                                       |
| <DemoLink script="create_a_title_figure"/>      | Customize a figure-based title. Such title images can be inserted into the Steam guide. |
| <DemoLink script="create_logo"/>                | Render the title bar of this readme file.                                               |
| <DemoLink script="render_latex_equations"/>     | Render a LaTeX equation as an image.                                                    |
| <DemoLink script="search_font"/>                | Search the font by name, and use the searched font to render an image.                  |
| <DemoLink script="composer_list"/>              | Generate examples for each image composer, and gather the results as an image.          |
| <DemoLink script="effect_list"/>                | Show the performance of all image layer effects in an image.                            |
