The tool used for creating grided images.

Its design is similar to matplotlib's subplots.

## Arguments

Initialization.

### ver. 1

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `n_cols` | `int` | <InlineIcon icon={vsiCheckIcon}/> | The number of rows in the grid. |
| `width` | `int` | | The width of the image. This width will be uniformly divided according to `n_cols`. |
| `margins` | `tuple[int, int]` | | The `(horizontal_margin, vertical_margin)` padded to the image. |
| `gaps` | `tuple[int, int]` | | The `(x_gap, y_gap)` defining the separations among images. |
| `bg_color` | `str \| tuple[float, ...] \| None` | | The background color of the whole image. If this value is `None`, will use transparent background. |
| `fmt` | `str \| ImageFormat` | | The format of the image. It is used only when saving this image. |
