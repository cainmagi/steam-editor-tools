An overlay layer with a linear gradient.

## Fields

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `color_a` | `str \| tuple[float, ...]` | <InlineIcon icon={vsiCheckIcon}/> | The starting RGB/RGBA color of the overlaying layer. |
| `color_b` | `str \| tuple[float, ...]` | <InlineIcon icon={vsiCheckIcon}/> | The ending RGB/RGBA color of the overlaying layer. |
| `size` | `tuple[int \| None, int \| None] \| None` | | The size of the gradient. If not specified, will use the layer size. |
| `direction` | `Literal["left_to_right", "top_to_bottom", "rect_center_to_outside", "radius_center_to_outside"]` | | The gradient direction. The value means the direction from `color_a` to `color_b`. |
| `pos_shift` | `tuple[int, int]` | | The shift of the overlaying content. By default, the content will be center- aligned with the giving shape. The overlaying content that is outside the shape mask will be cut off. |
| `mode` | `Literal["default", "add", "add_modulo", "screen", "lighter", "subtract", "subtract_modulo", "multiply", "darker", "difference", "soft_light", "hard_light"]` | | The blender mode of the overlaying effect. |

## Methods

### <IconObjType type="method"/> `overlay`

```python
v_1: Image | None = self.overlay(shape: Image)
```

Generate the overlay image from the given image.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `shape` | `Image` | <InlineIcon icon={vsiCheckIcon}/> | An `L` type image defining the shape of the overlay. This value is provided when rendering the overlaying effect. |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `Image \| None` | <p>The generated overlay image. This image can be not <code>RGBA</code>, but will be automatically converted to <code>RGBA</code> by applying the <code>self.shape</code> as the alpha channel. The size can be different from the input image. However, in most cases, this size should be the same as <code>self.shape</code>.</p><p>This image should be center-aligned with the input <code>self.shape</code>.</p><p>Will return <code>None</code> if the effect should be skipped.</p> |
