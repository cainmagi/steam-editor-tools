A layer of TeX equation that can be rendered as an image.

The image will be rendered every time when it is accessed.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `equation` | `str` | <InlineIcon icon={vsiCheckIcon}/> | <p>The LaTeX equation to be rendered.</p><p>Do not add <code>$</code> or <code>$$</code> symbol to the equation.</p> |
| `template` | `str \| TeXTemplate` | | <p>The LaTeX template used for rendering the equation. If using <code>str</code>, will treat this value as the template name.</p><p>The available templates can be found in <code>improc.variables.tex_templates</code>.</p> |
| `font_size` | `int \| str \| ImageFontAbsSize \| ImageFontSize` | | The dynamic font size of the rendered text. |
| `pad_size` | `int` | | The size used for padding on all sides of the text. |
| `color` | `str \| tuple[float, ...]` | | The text color. |
