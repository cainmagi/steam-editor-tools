The handle of a stack of layered images.

This class is inspired by the image editing software.

All modifications to this class is INPLACE. If the non-inplace modification is required, please use copy() method.

## Arguments

Initialization.

### ver. 1

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `width` | `int` | <InlineIcon icon={vsiCheckIcon}/> | The width of the canvas (this multi-layered image). |
| `height` | `int` | <InlineIcon icon={vsiCheckIcon}/> | The height of the canvas (this multi-layered image). |
| `fmt` | `str \| ImageFormat` | | The format of the image. It is used only when saving this image. |

### ver. 2

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `size` | `tuple[int, int]` | <InlineIcon icon={vsiCheckIcon}/> | The `(width, height)` of the canvas (this multi-layered image). |
| `fmt` | `str \| ImageFormat` | | The format of the image. It is used only when saving this image. |

### ver. 3

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `img` | `ImageSingle` | <InlineIcon icon={vsiCheckIcon}/> | The image used as the first layer of this multi-layered image. The canvas size will be the same as this image size. |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | The name of the first image layer (the layer is specified by `img`). |
| `fmt` | `str \| ImageFormat \| None` | | The format of the image. It is used only when saving this image. |

### ver. 4

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `img` | `ImageLayer \| ImageMultiLayer` | <InlineIcon icon={vsiCheckIcon}/> | The image used for initializing this image. If it is `ImageLayer`, will use this layer as the first layer. If it is `ImageMultiLayer`, will make a copy of the given `img`. |
| `fmt` | `str \| ImageFormat \| None` | | The format of the image. It is used only when saving this image. |
