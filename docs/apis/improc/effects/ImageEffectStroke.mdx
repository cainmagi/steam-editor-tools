The image effect: Stroke

Add the stroke effect to the alpha channel of the given image.

## Fields

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `mode` | `Literal["default", "add", "add_modulo", "screen", "lighter", "subtract", "subtract_modulo", "multiply", "darker", "difference", "soft_light", "hard_light"]` | | The blending mode of the stroke. |
| `type` | `Literal["stroke"]` | | The type code of this effect. It should not be modified. |
| `size` | `int` | | The size of the stroke. |
| `color` | `str \| tuple[float, ...]` | | The RGB/RGBA color of the stroke. |

## Methods
