The internal font list maintained by the `FontLocator`.

This list is designed for fast query.

## Arguments

No argument is needed.

### <IconObjType type="method"/> `query`

```python
v_1: list[tuple[FontInfo, str, float]] = self.query(
    name: str, lang: str | FontLanguage = FontLanguage.en, threshold: float = 70.0
)
```

Query the font.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | The name used for querying the font. Usually, the name is related to the language. |
| `lang` | `str \| FontLanguage` | | <p>The language of the font name. It will limit the searching scope of the fonts. The <code>name</code> argument should be consistent with this specified language.</p><p>If this value is <code>str</code>, will be treated as the label of <code>FontLanguage</code>.</p> |
| `threshold` | `float` | | The threshold for the matching rate. Any matched result with a score lower than this threshold will be filtered out. |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `list[tuple[FontInfo, str, float]]` | <p>A list of queried results. The results will be sorted by the matching rate. If no font can be found, will return an empty list.</p><p>Each item include:</p><ol><li>The searched font.</li><li>The name that the font is used for searching.</li><li>The matching rate of the searched font.</li></ol><p>Will not return more than five candidates.</p> |

### <IconObjType type="method"/> `query_best`

```python
v_1: tuple[FontInfo, str, float] | None = self.query_best(
    name: str, lang: str | FontLanguage = FontLanguage.en, threshold: float = 70.0
)
```

Query only one font.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | The name used for querying the font. Usually, the name is related to the language. |
| `lang` | `str \| FontLanguage` | | <p>The language of the font name. It will limit the searching scope of the fonts. The <code>name</code> argument should be consistent with this specified language.</p><p>If this value is <code>str</code>, will be treated as the label of <code>FontLanguage</code>.</p> |
| `threshold` | `float` | | The threshold for the matching rate. If the best matched font has a score lower than this value, will return `None`. |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `tuple[FontInfo, str, float] \| None` | <p>The best matched font. If no font can be found, will return <code>None</code>.</p><p>The returned values are</p><ol><li>The searched font.</li><li>The name that the font is used for searching.</li><li>The matching rate of the searched font.</li></ol> |
