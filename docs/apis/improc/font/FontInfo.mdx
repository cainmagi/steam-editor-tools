### <IconObjType type="method"/> `get_name`

```python
v_1: str = self.get_name(lang: str | FontLanguage = FontLanguage.en)
```

Get the best name of this font.

Will use the given language to search the font name. If not found, use the English language to search the font name. If still not found, will use the first available language of the font to get the font name.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `lang` | `str \| FontLanguage` | | The language name or code used for searching he font. |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | The best string name of the font. |
