The LaTeX renderer.

Render the LaTeX equation to pixel image. The backend is implemented by calling the `latex` command. Therefore, using this renderer requires the installation of a LaTeX released version.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `path_temp` | `str \| PathLike[str] \| None` | | The path to the folder storing the temporary files. If not specified, will create a folder in the temp path, |
| `verbose` | `bool` | | Whether to show the running details of LaTeX. |

Render the equation into a pixel-based image.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `equation` | `str` | <InlineIcon icon={vsiCheckIcon}/> | <p>The LaTeX equation. This equation is treated as a block equation.</p><p>Do not need to specify <code>$</code> or <code>$$</code> symbol.</p> |

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `out_file` | `str \| PathLike[str]` | <InlineIcon icon={vsiCheckIcon}/> | The path to the output file. |
| `equation` | `str` | <InlineIcon icon={vsiCheckIcon}/> | <p>The LaTeX equation. This equation is treated as a block equation.</p><p>Do not need to specify <code>$</code> or <code>$$</code> symbol.</p> |
