The image mixing operators extended to the alpha-channel (RGBA) domain.

This composer extends the scope of `ImageChops`, which only works with non- transparent images (such as `L` and `RGB`). Using this extended version, users can stack either `RGB` or `RGBA` images, where the stacking algorithm will take the alpha channel into consideration.

## Arguments

No argument is needed.

## Methods

### <IconObjType type="method"/> `threshold`

```python
v_1: Image = self.threshold(image: Image, threshold: int = 128)
```

Given a threshold, use this threshold to convert the image into a binary image.

If the image have multiple channels, will perform the conversion with respect to the luminance channel.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `image` | `Image` | <InlineIcon icon={vsiCheckIcon}/> | The image to be inverted. |
| `threshold` | `int` | | The threshold used for dividing the image. |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `Image` | The image mask in the mode "L" or "LA". Note that we do not perform the mode "1" conversion because the alpha channel needs to be preserved if it exists. |
