## Keywords

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `default` | `TeXTemplate` | <InlineIcon icon={vsiCheckIcon}/> | The default LaTeX template. |
| `chinese` | `TeXTemplate` | <InlineIcon icon={vsiCheckIcon}/> | The LaTeX template used for rendering equations containing Chinese. |
| `multilines` | `TeXTemplate` | <InlineIcon icon={vsiCheckIcon}/> | The LaTeX template only contains a bare equation environment. Use it for writing multi-line equations. |
| `multilines_chinese` | `TeXTemplate` | <InlineIcon icon={vsiCheckIcon}/> | The LaTeX template "multilines" with Chinese support. |
