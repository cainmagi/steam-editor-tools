Detect the achievements from a Steam game.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `app` | `int \| AppQuerySimple` | <InlineIcon icon={vsiCheckIcon}/> | The steam app ID or the query object. It is used for locating the game achievement page. |
| `lang` | `str` | | The language used for accessing the achievement profile. |
| `extra_user_profiles` | `Sequence[str] \| None` | | A list of extra Steam user profile names. If provided, will attempt to parse more achievement information from the given profiles. | Name | Type | <center>Description</center> |
