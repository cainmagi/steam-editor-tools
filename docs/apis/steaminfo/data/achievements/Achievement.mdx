The information of an achievement.

## Fields

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | Achievement display name. |
| `description` | `str` | | Description of the achievement. If extra user profiles are not provided, the description of a hidden achievement will not be detected. |
| `icon_url_locked` | `str \| None` | | Icon shown when achievement is locked. Need to be detected from a user profile when the achievement is locked. |
| `percent` | `float \| None` | | The percent of users who have unlocked this acheivement. Will be `None` if the value cannot be detected. |
| `icon_url` | `str` | <InlineIcon icon={vsiCheckIcon}/> | Icon shown when achievement is unlocked. |
| `is_hidden` | `bool \| None` | | A flag showing whether the achievement is hidden/spoiler-related. Need to be detected from extra user profiles. If this information is unknown, will be `None`. |
