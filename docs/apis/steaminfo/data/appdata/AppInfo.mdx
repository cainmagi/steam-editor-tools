The basic information of an app, provided by querying the ID.

## Fields

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `type` | `str` | <InlineIcon icon={vsiCheckIcon}/> | The type of the app. It should be "game" for most cases. |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | The app name. |
| `steam_appid` | `int` | <InlineIcon icon={vsiCheckIcon}/> | The app ID. |
| `required_age` | `int` | | The required age of the game. |
| `is_free` | `bool` | <InlineIcon icon={vsiCheckIcon}/> | Whether the game is free or not. |
| `controller_support` | `str \| None` | | How does it support the controller. |
| `dlc` | `list[int]` | | A list of DLCs' app IDs. |
| `detailed_description` | `str` | | A long game description formatted by HTML. |
| `about_the_game` | `str` | | A long game description displayed in the store page. It is ususally the same as "detailed_description". Formatted by HTML. |
| `short_description` | `str` | | A short game description displayed in the game title bar. |
| `supported_languages` | `str` | | The names of supported languages. It is formatted by HTML. |
| `reviews` | `str` | | The media reviews. It is formatted by HTML. |
| `header_image` | `str \| None` | | The URL of the header image. This is usually big. |
| `capsule_image` | `str \| None` | | The URL of the capsule image. This is usally smaller than header_image. |
| `capsule_imagev5` | `str \| None` | | The URL of the capsule v5 image. This is usally smaller than capsule_image. |
| `website` | `str \| None` | | The official website of the game. |
| `legal_notice` | `str \| None` | | The legal notice of the game. |
| `developers` | `list[str]` | | The list of developer names. |
| `publishers` | `list[str]` | | The list of publishers names. |
| `price_overview` | `AppPrice \| None` | | The price of the app. |
| `platforms` | `PlatformInfo \| None` | | The supported platform. |
| `metacritic` | `MetacriticInfo \| None` | | The metacritic information of the game. |
| `categories` | `list[AppCategory]` | | The related categories of the game. This list is displayed as tags on the store page. |
| `genres` | `list[AppCategory]` | | The related categories of the game. This list is displayed as game type. |
| `screenshots` | `list[AppScreenShot]` | | The list of screenshots. |
| `movies` | `list[AppMovie]` | | The list of moviews. |
| `release_date` | `AppDate \| None` | | The release date of the app. |
| `support_info` | `AppSupportInfo \| None` | | The support information of the app. |
| `background` | `str \| None` | | The background image of the store page. |
| `background_raw` | `str \| None` | | The background image (raw version) of the store page. |

| Name | Type | Required | <center>Description</center> |

| `raw` | `bool` | | Whether to get the raw version of the image. |

| Name | Type | <center>Description</center> |
