Parser for Steam Guide.

Pass the HTML file or URL of a Steam Guide. This parser will convert the guide to `Document`.

Note that the Steam rendering for the guide is heavily dependent to `<div>` tag. The reconstructions for line breaks in this parse may not be perfect.

## Arguments

Initialization function is not specified.
