The BBCode renderer with table format preferred.

This renderer variant will use the table format when rendering:

- unordered lists
- ordered lists

Such rendering conversions were used when writing reviews previously because the lists were not correctly rendered before.

However, since the Steam major update in 2026, the table is now rendered incorrectly. Therefore, currently, it is better to use `BBCodeRendererForReview` or `BBCodeRendererListPreferred`.
