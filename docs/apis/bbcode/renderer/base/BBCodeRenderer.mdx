```python
BBCodeRenderer(configs: BBCodeConfig | None = None)
```

The BBCode renderer.

Render the structured `Document` or an intemediate `Node` into the BBCode format.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `configs` | `BBCodeConfig \| None` | | <p>The configurations used for customizing the BBCode tags.</p><p>If not specified, will use <code>BBCodeConfig()</code> by default.</p> |

## Methods

### <IconObjType type="method"/> `render`

```python
v_1: str = self.render(node: Node | Document)
```

Render the BBCode.

Main dispatcher. Uses `node.type` directly so type checkers can narrow the union correctly.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `node` | `Node \| Document` | <InlineIcon icon={vsiCheckIcon}/> | The node or the document that would be rendered as BBCode. |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | The rendered BBCode text. |

### <IconObjType type="method"/> `render_table`

```python
v_1: str = self.render_table(node: TableNode)
```

Specific renderring. Render the table.

BBCode table syntax varies by forum. We adopt the Steam's format.

```bbcode
[table]
[tr][th]Header[/th][th]Header[/th][/tr]
[tr][td]Cell[/td][td]Cell[/td][/tr]
[/table]
```

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `node` | `TableNode` | <InlineIcon icon={vsiCheckIcon}/> | The table to be rendered. |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | The rendered table bbcode. |

| Name | Type | Required | <center>Description</center> |
