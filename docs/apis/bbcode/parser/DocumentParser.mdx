Document Parser.

This parser converts the other document formats (like BBCode, Markdown or HTML) to structured pydantic data.

## Arguments

No argument is needed.

## Methods

### <IconObjType type="method"/> `parse_achievements`

```python
v_1: Document = self.parse_achievements(
    ach_list: AchievementList,
    ach_parser: Callable[[str, Achievement], Node] | None = None,
)
```

Convert the list of achievements into a document.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `ach_list` | `AchievementList` | <InlineIcon icon={vsiCheckIcon}/> | The achievement list fetched from the online pages. This data collection can be provided by `steaminfo.get_achievement_list` |
| `ach_parser` | `Callable[[str, Achievement], Node] \| None` | | <p>An optional achievement data parser. It converts the data of a single achievement to a document node. If not specified, will use the default parser.</p><p>The first argument is the icon name. The second argument is the achievement information.</p> |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `Document` | The converted structured data of the achievement list. |
